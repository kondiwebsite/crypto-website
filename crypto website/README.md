# Aurex Markets Website Prototype

Aurex Markets is a static landing page prototype for a premium cryptocurrency and stock market intelligence platform. It showcases a modern dashboard-style UI with animated charts, market cards, featured insights, and a theme toggle.

## Project structure

- `index.html` - Main page layout and content.
- `css/styles.css` - Global styling, responsive layout, dark/light theme variables, and visual effects.
- `js/main.js` - Interactive behavior including scroll progress, cursor glow, mobile menu toggle, theme switching, reveal animations, and counter animations.

## Features

- Responsive landing page design
- Animated market widgets and dashboard preview
- Scroll progress indicator
- Dark / light theme toggle
- Mobile-friendly navigation
- Intersection observer reveal effects
- Animated numeric counters

## Usage

1. Open `index.html` in a web browser.
2. Alternatively, serve the folder with a local static server if needed.

## Optional local server

If you want to view the project with a local server, you can use any static server tool. For example:

- Python 3: `python -m http.server 8000`
- Node.js: `npx serve .`

Then open `http://localhost:8000` in your browser.

## Notes

- The project is purely static and does not require a build step.
- All assets are contained in the repository, with no external dependencies besides Google Fonts.
